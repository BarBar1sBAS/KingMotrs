# Animate · выразительное движение v2

Актуальная реализация от 6 октября 2026, по утверждённому владельцем плану. Цель — постановка первого экрана, объяснение последовательности ремонта, пространственная связь состояний и короткая обратная связь. Редкие маркетинговые сцены получают основной акцент; частые действия остаются быстрыми. Свободная прокрутка сохранена. Нет параллакса, циклов, звука, fake progress или новых библиотек.

## Доступность и жизненный цикл

Содержимое видно по умолчанию. IntersectionObserver запускает только входящие в экран элементы и снимает наблюдение после первого входа. Элементы ниже экрана не получают заранее скрывающих стилей. Нет зависимости доступности текста от IntersectionObserver или WAAPI. Шаги остаются нативным ol; новые линии aria-hidden.

Телефон и CTA первого экрана статичны и доступны сразу. Отказ sessionStorage пропускает всю вступительную сцену; прямой hash также её пропускает. Кнопка «Повторить интро» удалена при финальном ревью: посетителю она не нужна. Проверки интро запускают новую браузерную сессию. SVG path и красный не изменены; плашка не перехватывает указатель.

Клавиатурные открытия, Escape и прямые hash работают мгновенно. Клик по якорю запускает нативную плавную прокрутку. Hash сохраняется через pushState без предварительного скачка, фокус переводится с preventScroll. Фокус в секции завершает её декоративное движение и помечает сцены просмотренными. Нажатие кнопки с focus-visible не масштабируется. Закрывающееся меню inert, поэтому его исчезающие ссылки не получают Tab-фокус.

Повторное действие меняет целевое состояние CSS transition из текущей позиции. Таймер прошлого закрытия отменяется. Dialog остаётся в top layer до завершения pointer-exit; возврат содержимого, фокуса, hash и scroll выполняется один раз. Escape, запись и hash обходят задержку. Нативные details плавно меняют высоту содержимого через ::details-content. Клавиатура, hash и no-JS сохраняют мгновенное раскрытие.

Reduced motion немедленно отменяет WAAPI и CSS transitions, завершает pending close и оставляет конечные состояния доступными. Просмотренные сцены не повторяются после возврата настройки. pagehide очищает таймеры и анимации и закрывает диалог без перезаписи URL; pageshow из bfcache восстанавливает диалог по текущему hash и возвращает наблюдение только непросмотренным сценам.

Форма остаётся демонстрационной: никаких новых отправок или сохранения персональных данных. Карта и контакты не участвуют в сценах; внутренняя анимация стороннего iframe не управляется страницей.

## Плавные переходы по разделам и раскрытия

Клики по внутренним ссылкам, включая пункты меню и запись, используют scrollIntoView smooth. Длительность прокрутки определяет браузер. Повторная ссылка с тем же hash снова приводит к разделу. Колесо, касание и клавиатура отменяют незавершённую программную прокрутку; reduced motion завершает её у целевого раздела сразу.

Аккордеоны используют CSS block-size 0↔auto и content-visibility allow-discrete: соседние строки смещаются плавно в реальной компоновке. Повторное действие разворачивает незавершённый переход. Конечная высота auto сохраняет адаптивность и text200%. CSS включается только после JS-инициализации; no-JS и браузеры без поддержки intrinsic interpolation сохраняют обычное нативное раскрытие. Клавиатура и hash отключают анимацию размера. Общий токен --motion-accordion:240ms; --ease-drawer:cubic-bezier(.32,.72,0,1).

Модалки:280мс на вход,240мс на выход; opacity, scale.985→1 и translateY12→0 (6px mobile), ease-drawer. Backdrop синхронизирован. Escape и переход к записи закрывают диалог сразу, фокус и блокировка фона сохраняют прежний контракт.

scripts-v2/smooth-check.cjs включён в npm run verify. Проверяются промежуточная позиция прокрутки, повторный якорь, отмена reduced motion, промежуточные высоты открытия/закрытия FAQ, быстрый разворот, клавиатура, вложенные работы и модальный exit на390/1440. Результат: docs-v2/smooth-checks.json.

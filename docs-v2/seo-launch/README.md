# Кандидаты для будущего запуска

Эта папка не обслуживается локальным HTTP-сервером и не является готовым production-сайтом. Генерируется scripts-v2/seo.py при стандартной сборке. Ничего отсюда не отправлялось поисковикам.

- sitemap.xml: только https://kingmotors52.ru/. Якоря не отдельные страницы; noindex-архив legal.html и components.html исключены. lastmod не выдуман из даты каждой сборки.
- robots.txt: вариант для будущего статического сайта; не заменять им robots действующей CMS, где есть ограничения служебных путей. User-agent * относится в том числе к поисковым и AI-роботам; отдельная политика обучения требует решения владельца.
- llms.txt: необязательная карта содержания, не механизм повышения ранжирования. Нет способа надёжно применить HTML noindex к обычному txt на простом http.server, поэтому файл оставлен вне публичного прототипа.
- redirects.csv: 48 исходных маршрутов, 200 для корня и 47 кандидатов 301. Назначения сверены с актуальной docs-v2/content-map.md. Две правовые строки не активировать, пока legal.html остаётся архивом. Серверная конфигурация не реализована: хостинг ещё не выбран.

При реализации 301 сохранить fragment в Location, например /zamena-masla-v-dvigatele → https://kingmotors52.ru/#detail-zamena-masla-v-dvigatele. Корень не перенаправлять сам на себя. Нужны проверки trailing slash, HTTP/HTTPS, www и /index.html: один переход к окончательному адресу. Не применять catch-all «всё на /»: неизвестные адреса должны возвращать 404.

Перед запуском завершить условия PRODUCT.md: контакты/график/юридические документы, реальные изображения и права, условия диагностики/гарантии, рабочая серверная форма либо согласованный сценарий записи по телефону. Удалить демонстрационные состояния. Затем в отдельной production-сборке снять noindex только с утверждённой главной, перенести sitemap и согласованный robots. Служебные компоненты и локальные review-файлы в deploy не включать.

Проверить реальный ответ и X-Robots-Tag через curl; валидировать опубликованную разметку, подтвердить сайт в Яндекс Вебмастере/Google Search Console/Bing Webmaster Tools и подать sitemap. Эти действия не выполнены в текущем этапе. План измерения: ../seo-audit.md.

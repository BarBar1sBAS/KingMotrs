## Решения по чистоте кода

- DRY: повторные обработчики удалены; постоянные узлы диалога найдены один раз; два обхода карточек объединены. Сборка остаётся источником HTML, ручные правки только в dist не выполнялись.
- KISS: native dialog, details, links и buttons сохранены. Существующий единый app.js не раздроблен на искусственные модули. Параметры закрытия именованы, чтобы явно различать восстановление фокуса и изменение URL.
- YAGNI: нет новых зависимостей, классов, фабрик и настроек «на будущее». Основные сцены, команда и контент сохранены по решению владельца. Архивы и no-JS стили не удалялись как якобы неиспользуемые.
- SOLID: устранено смешение пользовательского закрытия с очисткой при навигации. Иерархии классов и интерфейсы для статической страницы не нужны. Защита фокуса, отмена таймеров, reduced motion и безопасный отказ storage сохранены.
- Код формы от объявления form до блока маркетинговых сцен совпадает с исходным побайтно. Её разметка, состояния, валидация и оформление не перерабатывались; передача услуги проверена.

## Сборка и размещение

`npm run build` создаёт главную, правовой архив, dist и ZIP по явному списку из 20 файлов. Пакет содержит только публичный HTML/CSS/JS, robots, используемые изображения, шрифты и лицензии. Playwright зафиксирован в package-lock.json, Python-зависимости — в requirements.txt. Путей конкретного компьютера в сборке и проверках нет. HTTP-сервер проверок запускается на свободном локальном порту и закрывается при успехе или ошибке. Ошибки проверок возвращают ненулевой exit code.

# КингМоторс · статический сайт v2

Текущая одностраничная версия находится в `prototype/`. `dist/` и `output-v2/KingMotors-static.zip` — готовый пакет для статического хостинга. Это демонстрационный сайт: форма ничего не отправляет, страницы сохраняют `noindex`. Публикация не выполнена.

## Установка

Нужны Python 3.9+ и Node.js 22+.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
npm ci
npx playwright install chromium
```

На Windows установка Python-зависимостей выполняется через `.venv\Scripts\python.exe`. Команды npm выбирают соответствующий интерпретатор автоматически. На Linux для браузера могут понадобиться системные зависимости: `npx playwright install --with-deps chromium`.

## Сборка и проверка

```sh
npm run build
npm run verify
npm run export
```

- `build`: генерирует нижние секции, главную и правовой архив, затем создаёт чистый `dist/` и воспроизводимый ZIP. Входные тексты и снимки источников не изменяются.
- `verify`: запускает временный HTTP-сервер на свободном локальном порту и проверяет именно `dist/`. Проверяет браузерные сценарии, HTTP, контент, состав пакета и две чистые повторные сборки. Любая ошибка завершает команду ненулевым кодом.
- `export`: снимает браузерные PNG из `prototype/`, включая служебный лист компонентов, затем собирает и рендерит PDF. Для изображения карты нужен доступ к Яндекс Картам. Внешний вид карты может меняться независимо от сайта.

Локальный просмотр готового пакета:

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory dist
```

Открыть http://127.0.0.1:8765. Остановить сервер: Ctrl+C.

## Размещение

Распаковать `output-v2/KingMotors-static.zip` и загрузить его содержимое в корень статического хостинга. `index.html` должен находиться прямо в корне, рядом с `assets/`. Сервер должен отдавать `/` с HTTP 200, неизвестные пути — с 404. Режим SPA/catch-all на главную не включать. Подкаталоги и серверная форма в этом пакете не предусмотрены.

Не загружать весь проект. Исходные материалы, инструкции, проверки, PDF, видео и `components.html` намеренно отсутствуют в `dist/`. Секретов и серверных настроек для конкретного провайдера нет.

Этот пакет не заменяет запуск рабочего сайта: для него отдельно нужны подтверждённые бизнес-данные, права на материалы, правовые документы и решение о приёме заявок. Кандидаты редиректов и sitemap остаются в `docs-v2/seo-launch/`, не активируются при сборке. Демоформа, предупреждения и noindex сохранены по решению владельца.

## Демонстрация в GitHub Pages

Актуальная демонстрация публикуется по адресу [barbar1sbas.github.io/KingMotrs](https://barbar1sbas.github.io/KingMotrs/).

Каждый push в `main` запускает GitHub Actions: среда устанавливает зависимости, выполняет `npm run build` и `npm run verify`, затем передаёт в GitHub Pages только содержимое `dist/`. Исходники, документы, снимки источников и экспортные материалы хранятся в репозитории, но не попадают в публичный артефакт сайта.

Для ручной публикации откройте вкладку **Actions**, выберите workflow **Deploy demo to GitHub Pages** и нажмите **Run workflow**. GitHub Pages должен использовать источник **GitHub Actions**.

## Структура

- `prototype/`: текущие CSS/JS, изображения, шрифты и сгенерированный HTML; общий источник токенов — `prototype/tokens.css`.
- `scripts-v2/`: сборка, проверки и экспорт. Playwright установлен локально, путей к конкретному компьютеру нет.
- `sources/`, `assets/original/`, `docs/content-register.md`, `docs/page-copy.md`: сохранённые источники и редакционные тексты, 48 URL.
- `assets/fonts/`: статические Golos с лицензией для PDF; браузер использует локальные variable-шрифты из `prototype/assets/`.
- `docs-v2/`: спецификация, отчёты и результаты проверок. Актуальные ревью — `technical-final.md` и `visual-final.md`.
- `output-v2/mockups/`, `output-v2/pdf/`: браузерные PNG и альбом `KingMotors-v2.pdf`. Видео прежнего этапа сохранены отдельно.

Отклонённая v1 и её сборщики удалены. Перед изменениями читать `AGENTS.md`. Внешние библиотеки на клиенте не используются.

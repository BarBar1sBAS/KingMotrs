## Одна страница: адресация и миграция

Новый сайт имеет один маркетинговый URL `/`, один H1 «Автосервис, которому можно доверить автомобиль» и один title «Автосервис КингМоторс - обслуживание и ремонт в Нижнем Новгороде». Остальные названия - H2 секций / H3 раскрываемого содержимого. Canonical главной - `/`. Не обещать сохранение позиций отдельных услуг: объединение URL меняет поисковую структуру и требует последующего наблюдения. Отдельных страниц услуг, вакансий, компании или корпоративного сервиса не создавать.

При 301 на URL с fragment сервер не получает fragment; JS при загрузке считывает `location.hash`, раскрывает целевой detail и его родительскую категорию, затем прокручивает к заголовку с учётом шапки. При ручном открытии синхронизирует fragment без перезагрузки. При отключённом JS все разделы присутствуют в HTML, нативные `<details>` доступны из каталога; показать ссылки на категории и услуги, не прятать содержимое за JS-only кнопками. Прямой fragment без JS может потребовать ручного раскрытия родительской категории - это известное ограничение, не выдавать его за автоматическое открытие во всех браузерах.
